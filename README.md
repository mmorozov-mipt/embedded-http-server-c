# Minimal HTTP Server in C (single-threaded, ESP32-friendly) ## Overview Легковесный однопоточный HTTP сервер на C, ориентированный на работу в условиях ограниченных ресурсов (например, ESP32). Сервер обслуживает статические файлы и демонстрирует основу для встроенных систем и IoT-устройств. Поддерживается отдача 3 типов контента: HTML, plain text, binary. ## Features - однопоточная архитектура - минимальное потребление памяти - простая модель обработки соединений - статические файлы без сторонних библиотек - базовая реализация HTTP 1.0 - кроссплатформенная сборка через CMake ## Supported routes / -> index.html /text -> text.txt /image -> image.bin ## Build Requirements - C compiler (gcc / clang) - CMake 3.10+ ## Build Instructions ``` mkdir build cd build cmake .. make ``` ## Run ``` ./http_server ``` По умолчанию сервер слушает порт 8080 (можно поменять в коде). ## Test in browser Открой: http://localhost:8080/ — главная страница http://localhost:8080/text — текстовый контент http://localhost:8080/image — бинарный контент ## Project structure ``` project_root ├── CMakeLists.txt ├── README.md └── main.c ``` ## Porting to ESP32 Проект может быть перенесен на ESP32: - заменить BSD-сокеты на esp-idf netconn API - перенести статические файлы во flash - отключить malloc-интенсивные части - оставить однопоточность ## Notes Это не full-featured веб-сервер. Цели проекта: - продемонстрировать сетевой стек на C - показать работу HTTP без фреймворков - быть основой для микроконтроллера или IoT устройства ## Disclaimer Проект создан для учебных и демонстрационных целей. Используйте на свой страх и риск. ```
