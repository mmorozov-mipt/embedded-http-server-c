# Minimal HTTP Server in C for Low-Resource Devices

Этот проект представляет собой однопоточный HTTP-сервер на языке C, ориентированный на запуск на микроконтроллерах с ограниченными ресурсами (ESP32 как ориентир). Сервер обслуживает статические файлы разных типов и размеров, поддерживает базовые HTTP-заголовки и корректные коды ответов.

## Возможности
- однопоточный режим работы
- минимальное потребление памяти
- отдача статических файлов по HTTP
- разные Content-Type (text/html, image/png, text/plain и др.)
- простая архитектура для портирования на микроконтроллеры

## Структура проекта
- main.c — реализация HTTP-сервера и обработка подключений
- CMakeLists.txt — сборка проекта через CMake
- static/ — директория со статическими файлами
  - index.html
  - info.txt
  - image.bin (пример бинарного контента)

## Как собрать (Linux / macOS)
1) установить CMake и компилятор C  
2) клонировать или распаковать проект  
3) в корне проекта выполнить:
   mkdir build && cd build  
   cmake ..  
   make  

## Как запустить
./http_server  
по умолчанию сервер слушает порт 8080

## Как проверить работу
1) открыть браузер
2) перейти по адресу:
   http://localhost:8080/
3) проверить выдачу файлов:
   /               — index.html  
   /info           — текстовый файл  
   /image          — бинарный контент  

## Под ESP32 / микроконтроллеры
- минимальные динамические аллокации
- без внешних зависимостей кроме стандартной библиотеки C
- легко адаптируется под FreeRTOS/ESP-IDF (замена socket API)

## Ограничения
- одновременное соединение одно
- не поддерживаются HTTPS и chunked encoding
- проект учебный, но архитектура приближена к продакшн-встраиваемым решениям

## Назначение проекта
- демонстрация сетевого стека на C
- портирование на MCU
- прохождение технических собеседований
- базовый HTTP-сервер для IoT-устройств
